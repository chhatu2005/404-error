
# Day 30 – 404 Error Page

## 📌 Project Overview
This project is a simple and responsive 404 Error Page created using HTML and CSS. It displays a friendly error message when a requested page cannot be found and provides a button to go back.

## ✨ Features
- Displays a large 404 error heading.
- Shows a Page Not Found message.
- Includes a search icon illustration.
- Provides a Go To Home button.
- Navigation bar with Home, About, Contact Us, Skill, and Project links.
- Background image and custom styling.
- Responsive layout for different screen sizes.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
```text
404-error-page/
├── index.html
├── style.css
├── image.png
└── README.md
```

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. View the 404 Error Page.
